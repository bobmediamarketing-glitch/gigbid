# Invoice auto-pay for a fintech client

**Date:** 2023-07-12  
**Client industry:** fintech  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using node.js, react, together with subscriptions, invoices and card payments; a relational database with migrations; a fully typed frontend and backend codebase.

## Result
The project served 5k users in the first quarter. The client extended the contract for a second phase.
