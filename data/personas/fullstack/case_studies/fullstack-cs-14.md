# Donation checkout for a healthcare client

**Date:** 2026-08-22  
**Client industry:** healthcare  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed subscription billing with trials and coupons.

## What I built
I delivered the project using stripe, together with a fully typed frontend and backend codebase; a component-based single-page frontend.

## Result
The project cut manual effort by 44%. The client extended the contract for a second phase.
