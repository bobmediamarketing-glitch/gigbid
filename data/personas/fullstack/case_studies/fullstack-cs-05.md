# Collaborative whiteboard for a real estate client

**Date:** 2023-07-28  
**Client industry:** real estate  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed live order status updates without refreshing.

## What I built
I delivered the project using websockets, together with an in-memory cache and message broker; a relational database with migrations.

## Result
The project reduced latency from 7s to 302ms. The client extended the contract for a second phase.
