# Logistics tracking API for a education client

**Date:** 2024-09-26  
**Client industry:** education  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using django, postgres, together with an in-memory cache and message broker; a JavaScript server runtime; a single typed query endpoint for the frontend.

## Result
The project cut manual effort by 58%. The client extended the contract for a second phase.
