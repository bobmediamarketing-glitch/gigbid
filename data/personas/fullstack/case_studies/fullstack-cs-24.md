# Donation checkout for a logistics client

**Date:** 2023-05-02  
**Client industry:** logistics  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using react, postgres, together with subscriptions, invoices and card payments; a fully typed frontend and backend codebase; a JavaScript server runtime.

## Result
The project cut manual effort by 57%. The client extended the contract for a second phase.
