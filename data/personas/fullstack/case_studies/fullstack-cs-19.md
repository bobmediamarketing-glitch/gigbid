# Usage-based billing for a media client

**Date:** 2025-11-06  
**Client industry:** media  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using node.js, together with a relational database with migrations; subscriptions, invoices and card payments.

## Result
The project cut manual effort by 69%. The client extended the contract for a second phase.
