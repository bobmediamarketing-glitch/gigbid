# Multi-tenant CRM backend for a travel client

**Date:** 2023-11-14  
**Client industry:** travel  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using fastapi, node.js, together with a single typed query endpoint for the frontend; an in-memory cache and message broker; a batteries-included Python web framework.

## Result
The project reached 93% accuracy on a held-out set. The client extended the contract for a second phase.
