# Trading alerts feed for a e-commerce client

**Date:** 2026-03-07  
**Client industry:** e-commerce  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using postgres, websockets, together with a component-based single-page frontend; a JavaScript server runtime; an in-memory cache and message broker.

## Result
The project reduced latency from 6s to 557ms. The client extended the contract for a second phase.
