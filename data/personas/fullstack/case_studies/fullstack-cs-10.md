# Collaborative whiteboard for a fintech client

**Date:** 2025-09-10  
**Client industry:** fintech  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using react, typescript, together with an in-memory cache and message broker; a relational database with migrations; a JavaScript server runtime.

## Result
The project saved the client $21k per month. The client extended the contract for a second phase.
