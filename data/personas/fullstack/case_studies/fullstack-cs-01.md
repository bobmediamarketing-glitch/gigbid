# Clinic booking SaaS for a fintech client

**Date:** 2023-04-06  
**Client industry:** fintech  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using aws, prisma, together with a component-based single-page frontend; utility-first styling; server-rendered pages with file-based routing.

## Result
The project served 35k users in the first quarter. The client extended the contract for a second phase.
