# Live auction dashboard for a marketing client

**Date:** 2024-03-02  
**Client industry:** marketing  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using node.js, redis, together with a fully typed frontend and backend codebase; live updates pushed to the browser; a relational database with migrations.

## Result
The project served 47k users in the first quarter. The client extended the contract for a second phase.
