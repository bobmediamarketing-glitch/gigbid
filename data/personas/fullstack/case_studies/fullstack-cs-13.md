# Telehealth scheduling API for a insurance client

**Date:** 2023-11-03  
**Client industry:** insurance  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using redis, fastapi, together with a minimal JavaScript HTTP API; a JavaScript server runtime; a single typed query endpoint for the frontend.

## Result
The project saved the client $5k per month. The client extended the contract for a second phase.
