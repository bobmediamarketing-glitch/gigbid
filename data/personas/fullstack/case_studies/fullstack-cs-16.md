# Clinic booking SaaS for a real estate client

**Date:** 2024-03-05  
**Client industry:** real estate  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a fast marketing site plus logged-in dashboard.

## What I built
I delivered the project using next.js, postgres, together with a fully typed frontend and backend codebase; a type-safe ORM layer.

## Result
The project reduced latency from 7s to 367ms. The client extended the contract for a second phase.
