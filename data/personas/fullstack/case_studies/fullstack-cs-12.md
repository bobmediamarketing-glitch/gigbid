# Print-on-demand storefront for a logistics client

**Date:** 2026-04-21  
**Client industry:** logistics  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a fast marketing site plus logged-in dashboard.

## What I built
I delivered the project using next.js, postgres, together with a component-based single-page frontend; a JavaScript server runtime; subscriptions, invoices and card payments.

## Result
The project reached 94% accuracy on a held-out set. The client extended the contract for a second phase.
