# Logistics tracking API for a fintech client

**Date:** 2025-07-09  
**Client industry:** fintech  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using node.js, docker, together with a single typed query endpoint for the frontend; a relational database with migrations; an async Python API with automatic docs.

## Result
The project reached 91% accuracy on a held-out set. The client extended the contract for a second phase.
