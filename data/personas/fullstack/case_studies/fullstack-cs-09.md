# Marketplace payouts for a legal client

**Date:** 2023-05-06  
**Client industry:** legal  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using postgres, stripe, together with a fully typed frontend and backend codebase; a JavaScript server runtime; a component-based single-page frontend.

## Result
The project reduced latency from 8s to 630ms. The client extended the contract for a second phase.
