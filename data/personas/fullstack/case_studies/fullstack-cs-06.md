# Course creator platform for a media client

**Date:** 2026-01-14  
**Client industry:** media  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed subscription billing with trials and coupons.

## What I built
I delivered the project using stripe, together with a relational database with migrations; a fully typed frontend and backend codebase.

## Result
The project cut manual effort by 73%. The client extended the contract for a second phase.
