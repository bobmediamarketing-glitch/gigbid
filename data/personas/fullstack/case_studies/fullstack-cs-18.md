# Telehealth scheduling API for a media client

**Date:** 2026-04-11  
**Client industry:** media  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using express, node.js, together with a single typed query endpoint for the frontend; a batteries-included Python web framework.

## Result
The project reduced latency from 9s to 889ms. The client extended the contract for a second phase.
