# Print-on-demand storefront for a e-commerce client

**Date:** 2024-08-08  
**Client industry:** e-commerce  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a fast marketing site plus logged-in dashboard.

## What I built
I delivered the project using next.js, together with subscriptions, invoices and card payments; a JavaScript server runtime.

## Result
The project saved the client $15k per month. The client extended the contract for a second phase.
