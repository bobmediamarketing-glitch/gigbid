# Contract search copilot for a marketing client

**Date:** 2024-02-11  
**Client industry:** marketing  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using nlp, langchain, together with an async Python API with automatic docs; open-weight transformer checkpoints; answering questions from the client's own documents with citations.

## Result
The project reduced latency from 8s to 780ms. The client extended the contract for a second phase.
