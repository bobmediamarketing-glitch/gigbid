# Contract search copilot for a healthcare client

**Date:** 2026-08-27  
**Client industry:** healthcare  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using python, together with answering questions from the client's own documents with citations; a self-hosted vector database.

## Result
The project saved the client $24k per month. The client extended the contract for a second phase.
