# Defect inspection model for a travel client

**Date:** 2023-06-04  
**Client industry:** travel  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using pytorch, aws, together with classic image preprocessing and contour detection; containerised services; scripting the whole pipeline end to end.

## Result
The project reached 88% accuracy on a held-out set. The client extended the contract for a second phase.
