# Model registry rollout for a fintech client

**Date:** 2023-12-01  
**Client industry:** fintech  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using mlflow, together with automated retraining and model monitoring; a background task queue with workers and retries.

## Result
The project saved the client $2k per month. The client extended the contract for a second phase.
