# Demand forecast pipeline for a saas client

**Date:** 2025-01-26  
**Client industry:** saas  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed moving slow report generation off the request path.

## What I built
I delivered the project using celery, aws, together with automated retraining and model monitoring; tracking experiments and model versions; scripting the whole pipeline end to end.

## Result
The project cut manual effort by 65%. The client extended the contract for a second phase.
