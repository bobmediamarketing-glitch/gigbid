# Parking occupancy counter for a saas client

**Date:** 2024-06-15  
**Client industry:** saas  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using docker, together with classic image preprocessing and contour detection; Amazon cloud hosting.

## Result
The project reached 90% accuracy on a held-out set. The client extended the contract for a second phase.
