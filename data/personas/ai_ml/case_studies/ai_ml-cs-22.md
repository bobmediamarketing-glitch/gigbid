# Claims processing agent for a healthcare client

**Date:** 2026-08-03  
**Client industry:** healthcare  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed LLM tool calling over our existing APIs.

## What I built
I delivered the project using langchain, celery, together with containerised services; an async Python API with automatic docs.

## Result
The project saved the client $30k per month. The client extended the contract for a second phase.
