# Contract search copilot for a e-commerce client

**Date:** 2024-02-10  
**Client industry:** e-commerce  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed LLM tool calling over our existing APIs.

## What I built
I delivered the project using langchain, pinecone, together with extracting entities and intent from free text; an async Python API with automatic docs; open-weight transformer checkpoints.

## Result
The project cut manual effort by 73%. The client extended the contract for a second phase.
