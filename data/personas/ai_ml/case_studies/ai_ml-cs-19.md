# Churn model serving platform for a e-commerce client

**Date:** 2026-08-02  
**Client industry:** e-commerce  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using mlflow, together with a background task queue with workers and retries; an async Python API with automatic docs.

## Result
The project served 57k users in the first quarter. The client extended the contract for a second phase.
