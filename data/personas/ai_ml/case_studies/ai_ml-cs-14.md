# Demand forecast pipeline for a insurance client

**Date:** 2024-01-19  
**Client industry:** insurance  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a retraining job that runs weekly and alerts on drift.

## What I built
I delivered the project using mlops, mlflow, together with an async Python API with automatic docs; scripting the whole pipeline end to end; containerised services.

## Result
The project saved the client $4k per month. The client extended the contract for a second phase.
