# Claims processing agent for a real estate client

**Date:** 2023-09-15  
**Client industry:** real estate  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed an agent workflow that can pause for a manager to approve.

## What I built
I delivered the project using langgraph, langchain, together with an in-memory cache and message broker; a background task queue with workers and retries.

## Result
The project served 2k users in the first quarter. The client extended the contract for a second phase.
