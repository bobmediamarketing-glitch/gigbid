# Claims processing agent for a legal client

**Date:** 2025-08-10  
**Client industry:** legal  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using docker, together with answering questions from the client's own documents with citations; an async Python API with automatic docs.

## Result
The project reached 92% accuracy on a held-out set. The client extended the contract for a second phase.
