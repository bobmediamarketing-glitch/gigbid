# Recruiting screener agent for a insurance client

**Date:** 2024-03-17  
**Client industry:** insurance  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed an agent workflow that can pause for a manager to approve.

## What I built
I delivered the project using langgraph, together with an async Python API with automatic docs; a background task queue with workers and retries.

## Result
The project reached 91% accuracy on a held-out set. The client extended the contract for a second phase.
