# Policy Q&A assistant for a logistics client

**Date:** 2025-08-26  
**Client industry:** logistics  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed LLM tool calling over our existing APIs.

## What I built
I delivered the project using langchain, pinecone, together with open-weight transformer checkpoints; scripting the whole pipeline end to end; answering questions from the client's own documents with citations.

## Result
The project served 86k users in the first quarter. The client extended the contract for a second phase.
