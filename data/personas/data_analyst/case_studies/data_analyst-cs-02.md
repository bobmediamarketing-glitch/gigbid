# Shopify to Snowflake pipeline for a marketing client

**Date:** 2023-08-04  
**Client industry:** marketing  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using bigquery, dbt, together with scripting the whole pipeline end to end; hand-written analytical queries with window functions; scheduled DAGs that orchestrate nightly loads.

## Result
The project reduced latency from 6s to 751ms. The client extended the contract for a second phase.
