# Store performance scorecard for a saas client

**Date:** 2023-07-18  
**Client industry:** saas  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using bigquery, together with interactive visual dashboards for executives; a semantic layer with governed metrics.

## Result
The project reduced latency from 6s to 794ms. The client extended the contract for a second phase.
