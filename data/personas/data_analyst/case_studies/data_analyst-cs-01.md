# Marketing attribution report for a e-commerce client

**Date:** 2024-04-12  
**Client industry:** e-commerce  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using tableau, together with Google's serverless warehouse; a semantic layer with governed metrics.

## Result
The project reached 97% accuracy on a held-out set. The client extended the contract for a second phase.
