# Store performance scorecard for a marketing client

**Date:** 2025-12-07  
**Client industry:** marketing  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using looker, together with Google's serverless warehouse; hand-written analytical queries with window functions.

## Result
The project reduced latency from 8s to 432ms. The client extended the contract for a second phase.
