# Email subject-line test for a real estate client

**Date:** 2023-08-04  
**Client industry:** real estate  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using statistics, a/b testing, together with scripting the whole pipeline end to end; hand-written analytical queries with window functions.

## Result
The project reduced latency from 12s to 339ms. The client extended the contract for a second phase.
