# Commission calculator rebuild for a insurance client

**Date:** 2023-08-19  
**Client industry:** insurance  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using pandas, power bi, together with spreadsheet models with macros; scripting the whole pipeline end to end.

## Result
The project served 16k users in the first quarter. The client extended the contract for a second phase.
