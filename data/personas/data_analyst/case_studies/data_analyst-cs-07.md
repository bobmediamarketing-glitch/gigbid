# Finance close automation for a insurance client

**Date:** 2024-02-03  
**Client industry:** insurance  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed clean, tested models on top of raw Shopify exports.

## What I built
I delivered the project using dbt, together with a cloud data warehouse with separate compute; hand-written analytical queries with window functions.

## Result
The project saved the client $12k per month. The client extended the contract for a second phase.
