# Store performance scorecard for a healthcare client

**Date:** 2023-11-18  
**Client industry:** healthcare  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using looker, bigquery, together with hand-written analytical queries with window functions; Microsoft dashboards for the finance team; spreadsheet models with macros.

## Result
The project saved the client $25k per month. The client extended the contract for a second phase.
