# Pricing elasticity analysis for a real estate client

**Date:** 2023-08-06  
**Client industry:** real estate  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using pandas, postgres, together with hand-written analytical queries with window functions; Google's serverless warehouse.

## Result
The project saved the client $24k per month. The client extended the contract for a second phase.
