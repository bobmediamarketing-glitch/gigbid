# Budget consolidation workbook for a fintech client

**Date:** 2026-02-06  
**Client industry:** fintech  
**Role:** sole developer

## Problem
The client's team was doing this work by hand and it did not scale. They needed a reliable system they could own.

## What I built
I delivered the project using python, pandas, together with Microsoft dashboards for the finance team; spreadsheet models with macros.
